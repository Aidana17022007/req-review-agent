Дизайн-система v3 «Ecliptic Dawn»

Единые токены, компоненты, иконки и логотип для трёх поверхностей: сайт, приложение (Studio) и HTML-отчёт. Спокойный, точный инструмент аналитика: ночные панели на градиенте рассвета, кобальт и перивинкл, семантика серьёзности, сетка 4/8 pt, контраст текста WCAG AA в обеих темах, анимации не дольше 200 мс.

Сборка: python -m req_review.ui.styleguide (tokens.css, эта страница, слайды) · логотип и иконки PWA: python -m req_review.ui.brand → design/brand/

Логотип

знак + слово · светлый / тёмный фон

Знак — линза с галочкой: агент «смотрит» на требования и подтверждает качество. Минимальный размер знака — 16 px, вокруг логотипа — свободное поле не меньше высоты галочки. Не перекрашивать, не вращать, не добавлять тени.

Иконки приложения (PWA) и favicon · design/brand/

maskable показан в круглой маске — глиф целиком в безопасной зоне. theme_color #02030C, background_color #F5F6FC (тёмная — #02030C) — в design/brand/brand.json.
