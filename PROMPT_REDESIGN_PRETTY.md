## Роль и цель

Ты — senior продуктовый дизайнер и фронтенд-разработчик. Проект — **ReqLens**, ИИ-агент статической проверки требований
по ISO/IEC/IEEE 29148 и IEEE 830 (Python, Jinja2-шаблоны, один CSS `req_review/ui/assets/base.css`, токены в
`design/tokens.json`). Нужно сделать так, чтобы **лендинг-сайт, веб-студия (Studio), HTML-отчёт, витрина стилей, слайды,
иконки/PWA и скриншоты в README выглядели как один продукт** — в эстетике шаблона Oversight **«Pretty»**
(https://supply.madebyoversight.com/templates/pretty): тёмный, утончённый AI-SaaS, почти чёрный фон, матовые
стеклянные карточки, мягкое зелёное свечение.

Важно: **не копируй** код, тексты, изображения или вёрстку шаблона Pretty — он платный. Используй только общее
визуальное направление, описанное ниже, и собственный контент ReqLens.

## Визуальный язык (описание стиля)

**Настроение:** спокойная премиальность, «инструмент, который просто работает». Много воздуха, мало цвета, цвет — только
как акцент и свет.

**Фон и поверхности (тёмная тема — основная):**
- фон страницы `#0B0D0C` (почти чёрный, с едва заметным зелёным оттенком), в hero — большое размытое зелёное свечение
  (radial-gradient `rgba(76,192,127,.18)` → прозрачный, blur 120–160px) из левого-нижнего угла, плюс лёгкий шум/зерно (SVG noise, opacity ≈ .04);
- поверхности: `surface #141716`, `surface-2 #1B1F1D`, приподнятые карточки `#202523`;
- «стекло»: `background: rgba(255,255,255,.03)`, `border: 1px solid rgba(255,255,255,.08)`,
  `backdrop-filter: blur(16px)`, внутренний блик сверху `inset 0 1px 0 rgba(255,255,255,.06)`;
- тени глубокие и мягкие: `0 24px 60px rgba(0,0,0,.45)`.

**Текст:** основной `#EDEFEE`, вторичный `#9BA39F`, третичный `#6E7671`. Заголовки — крупные, плотные,
`letter-spacing: -0.02em … -0.035em`, вес 600; второй строкой заголовка допустим приглушённый цвет (двухтоновый заголовок).

**Бренд-зелёный (сохраняем наш цвет, но «светящийся»):**
- основной акцент на тёмном `#4CC07F`, hover `#6FD49A`, глубокий `#1F6B45` (наш `theme_color`), мягкий фон `rgba(76,192,127,.12)`;
- зелёный используется: в свечении фона, в индикаторах статуса, в фокусе, в одной главной кнопке/акценте на экран — не больше.

**Кнопки:**
- primary — светлая «таблетка»: фон `#EDEFEE`, текст `#0B0D0C`, радиус 999px, высота 40–44px, лёгкий внутренний градиент;
- secondary — тёмное стекло с тонкой рамкой `rgba(255,255,255,.12)`;
- brand (только для главного действия «Проверить документ») — зелёная с мягким свечением `0 0 24px rgba(76,192,127,.35)`.

**Карточки:** радиус 20–24px, стекло, внутри — мини-превью интерфейса (наклонённые 3D-карточки с `transform: perspective(1000px) rotateX(8deg) rotateY(-12deg)`), подпись снизу: заголовок 15px/600 + описание 13–14px вторичным цветом.

**Чипы/бейджи:** маленькие таблетки 12px, тёмный фон, цветная точка слева. Серьёзности сохраняем, но адаптируем под тёмный стиль:
критичное `#FF7A70`, существенное `#F2C26B`, незначительное `#E3D47A`, ок `#6FD49A`, инфо `#8DB8F0` (каждое с `-soft` фоном ~14% непрозрачности). Контраст текста ≥ 4.5 (WCAG AA).

**Типографика:** `Inter` (или `Geist`) для текста, `JetBrains Mono` для кода/ID требований. Шкала: display 56–64px (мобильный 36–40px),
h1 40px, h2 28px, h3 18px, body 15–16px/1.6, small 13px, caption 12px с `letter-spacing: .02em`.

**Движение:** появление блоков fade+translateY(12px) 280ms `cubic-bezier(.2,.8,.2,1)`, hover карточек — подъём на 2px и
усиление рамки; свечение в hero медленно «дышит» (8–12 с). Всё отключается при `prefers-reduced-motion`.

**Светлая тема (вторичная, но обязательная):** тот же характер на светлом: фон `#F4F5F4`, поверхности `#FFFFFF`, стекло
`rgba(255,255,255,.7)`, рамки `rgba(0,0,0,.08)`, бренд `#1F6B45`, свечение зелёное, но слабее (`.10`). Тёмная тема — по умолчанию на сайте.

## ЭТАП 1 — сайт (лендинг)

Сделай одностраничный адаптивный сайт в `site/` (чистый HTML + CSS + немного JS, без фреймворков, без внешних трекеров;
стили берутся из `req_review/ui/tokens.css` + отдельный `site/site.css`, чтобы сайт и приложение делили токены).

Секции (весь текст — свой, на русском, с переключателем RU / KK, как в отчёте):
1. **Навигация** — стеклянная плавающая панель: знак ReqLens, ссылки (Возможности, Как работает, Бенчмарк, GitHub), кнопки «Демо» (secondary) и «Проверить документ» (brand).
2. **Hero** — двухтоновый заголовок: «Найдите дефекты в требованиях / до того, как их найдёт разработка.» Подзаголовок про ISO 29148 / IEEE 830 и отчёт на русском. Две кнопки. Под ними — большой «экран приложения» в стеклянной рамке: настоящий скриншот `docs/assets/screenshot-doc-dark.png` (подсвеченные дефекты), поверх — 2–3 плавающие карточки-замечания (🔴 критичное R-006, цитата, «как исправить»), слегка наклонённые.
3. **Полоса доверия** — бейджи стандартов: ISO/IEC/IEEE 29148:2018, IEEE 830-1998, Gemini / OpenAI-compatible / Ollama, офлайн-режим.
4. **Цифры** — крупные KPI из README: 26 из 26 ожидаемых дефектов, recall 100 %, precision 98 %, 43 требования / 75 замечаний.
5. **«Всё, что нужно для ревью требований»** — горизонтальная лента/сетка из 10 стеклянных карточек (тест-проба Given/When/Then, интерактивный отчёт, автоисправление, защита от галлюцинаций, финтех-чек-лист, метрики, офлайн, для команды, 3D-граф, Studio + ассистент). В каждой — мини-иллюстрация из реального UI (кроп скриншотов из `docs/assets/`), не стоковая графика.
6. **Как это работает** — 4 шага со stepper-линией: загрузка → выделение требований → проверка + критик → отчёт и исправления. Можно вставить `docs/assets/live-run.gif`.
7. **Скриншоты** — табы: Документ / 3D-граф / Тесты / Исправления / Studio (тёмные скриншоты).
8. **Бенчмарк** — таблица 5 документов, 67 дефектов (данные из `bench/RESULTS.md`).
9. **Быстрый старт** — блок кода с кнопкой «скопировать»: `python review.py bench/real/notifications.md reports/report.md --profile deep`.
10. **CTA** — большой стеклянный блок с зелёным свечением + **футер** (команда из `docs/team.yaml`, ссылки, лицензия).

Требования: адаптив 360 / 768 / 1280 / 1440px, без горизонтального скролла; Lighthouse ≥ 90 по Performance и Accessibility;
изображения в WebP с `width/height` и `loading="lazy"`; семантичная вёрстка, alt-тексты, фокус виден; работает без JS
(JS — только анимации, табы, копирование, тема, язык).

## ЭТАП 2 — после готовности сайта: весь проект под дизайн сайта

Источник правды остаётся один — `design/tokens.json`. Порядок работы:

1. **Токены.** Обнови `design/tokens.json` до версии `4.0.0`, `system: "Дизайн-система v3 — Glass Dark"`:
   новые значения `color.dark` / `color.light` из раздела «Визуальный язык», добавь группы `glass` (bg, border, blur, highlight),
   `glow` (brand, hero), `shadow.xl`, радиусы `card: 22px`, `hero: 28px`, шрифтовые роли `display` 56px. Пересобери:
   `python -m req_review.ui.styleguide` (→ `tokens.css`, витрина, слайды). `tokens.css` руками не правь.
2. **Компоненты `base.css`.** Перерисуй все классы из `docs/DESIGN_SYSTEM.md` (кнопки, поля, dropzone, чипы, карточки, KPI,
   таблица, табы, seg, drawer, modal, toast, tooltip, stages/stepper, empty, skeleton) в стеклянном стиле, используя **только
   семантические токены**. Имена классов и разметку не меняй — шаблоны и JS должны работать без правок логики.
3. **Studio** (`req_review/ui/templates/studio.html.j2`) — тёмная тема по умолчанию, стеклянный сайдбар, фоновое свечение
   как на сайте, dropzone с зелёным пунктиром и свечением при `.is-over`, живой прогон и ассистент — в стеклянных панелях.
4. **HTML-отчёт** (`report.html.j2`, `report.js`, `report-graph.js`) — тот же вид, но **оставь офлайн-однофайловость**
   (никаких внешних шрифтов/CDN: шрифт — системный fallback или встроенный subset). Подчёркивания дефектов, миникарта,
   карточка замечания, радар, 3D-граф (фон `#0B0D0C`, узлы — цвета серьёзности, рёбра противоречий красные со свечением).
   Печать в PDF — светлая тема, без свечений и blur.
5. **Витрина** `styleguide.html.j2` и **слайды** `slides.html.j2` / `docs/slides.html` — в том же стиле, что сайт.
6. **Бренд** (`req_review/ui/brand.py` → `design/brand/`): знак ReqLens на тёмной плитке с зелёным свечением; обнови
   `favicon.svg`, PNG-иконки, `maskable`, `brand.json` (`theme_color #0B0D0C` для тёмной, `#1F6B45` остаётся брендом),
   `req_review/web/static/manifest.webmanifest`, `offline.html`, `docs/assets/banner.svg`.
7. **Скриншоты и GIF** — перегенерируй `python scripts/screenshots.py`; в README сначала тёмные версии.
8. **Документация** — обнови `docs/DESIGN_SYSTEM.md` (новые токены, glass/glow, правила свечения: максимум один источник на экран).
