# Принятые решения и компромиссы (ReqLens v2)

| # | Решение | Почему / компромисс |
|---|---|---|
| 1 | Основной отчёт остаётся `report.md` по пути из второго аргумента; остальные артефакты кладутся рядом с префиксом имени отчёта: `report.html`, `report.json`, `report_requirements_fixed.md`, `report_traceability.xlsx`, `report_jira_import.csv` | ТЗ требует отчёт по указанному пути; префикс исключает перезапись файлов при нескольких прогонах в одну папку |
| 2 | Тест-проба (Gherkin) и тип EARS запрашиваются **в том же запросе**, что и проверка требований | Число обращений к модели не растёт — укладываемся в бесплатный тариф Gemini |
| 3 | Доменный чек-лист и глоссарий — **один** общий запрос | Экономия квоты; обе задачи читают весь документ |
| 4 | Вопросы заказчику строятся из замечаний **без обращения к модели** | Ноль дополнительных запросов, детерминированный результат |
| 5 | Профиль `fast` по умолчанию: критик и повторная оценка выключены; `full` включает их | На бесплатном тарифе критик и `--rescore` удлиняют прогон; для демо — `--profile full` |
| 6 | Без подтверждённой цитаты область финтех-чек-листа считается «не покрытой» | Та же защита от галлюцинаций, что и для замечаний |
| 7 | Замечания тест-пробы не может отклонить критик | Невозможность написать тест — объективный факт, подтверждённый цитатой |
| 8 | Шрифт Inter не встраивается base64 — используется системный стек `Inter, Segoe UI, Roboto…` | Встраивание woff2 потребовало бы скачивать файлы шрифтов из внешнего источника и увеличило бы отчёт на ~300 КБ; на машинах с Inter он подхватывается автоматически |
| 9 | Цвета серьёзности для текста в светлой теме затемнены относительно акцентных (#D92D33, #B76E00, #8A6A00, #0E8A52); исходные цвета из ТЗ промпта сохранены как `*-accent` для заливок и подчёркиваний | Контраст WCAG AA для мелкого текста на светлом фоне |
| 10 | Вместо мини-радара в каждой карточке требования — полоса из 9 квадратиков (по критерию) с подсказками | На ширине карточки радар из 9 осей нечитаем; полоса читается мгновенно и не ломается на мобильных |
| 11 | Граф — собственная force-directed раскладка на JS + SVG, без библиотек | Отчёт полностью офлайн, без CDN |
| 12 | Веб-студия на FastAPI + ванильный JS, события прогона через SSE | Никаких сборщиков фронтенда; ключ модели живёт только на сервере |
| 13 | Кэш ответов модели (`.cache/llm`, ключ — хэш провайдера, модели, температуры и промпта) включён по умолчанию для реальных моделей, выключен для mock и в тестах | Повторный прогон того же документа не тратит квоту; `LLM_CACHE=0` выключает |
| 14 | `--compare` принимает либо `report.json` прошлого прогона (без запросов к модели), либо старую версию документа (полный прогон) | JSON — быстрый путь; документ — когда прошлого прогона нет |
| 15 | Precision в бенчмарке считается по существенным и критичным замечаниям; замечания к заведомо «чистым» требованиям — ложные | Незначительные (стилистические) замечания к чистым требованиям часто справедливы и не должны штрафоваться |
| 16 | Длинные строки (регулярки, промпты) допускаются: в ruff отключён E501 | Разбиение регулярных выражений ухудшает читаемость |
| 17 | Офлайн-профиль использует существующий OpenAI-совместимый клиент с `OPENAI_BASE_URL=http://localhost:11434/v1` (Ollama) | Ноль новых зависимостей; любая локальная модель с OpenAI-API |
| 18 | UI v3: структура «AI-агент» (карточка агента со статусом, таймлайн «Трассировка агента», таблица требований) в светлой зелёной теме; сайдбар-навигация: Обзор · Требования · Проверка набора · Трассировка · Экспорт | По макетам заказчика; данные и формат отчёта не менялись — только представление |
| 19 | Тёмная тема — только по переключателю, по умолчанию всегда светлая (настройка ОС не учитывается) | Основная тема продукта — светлая зелёная; отчёт должен выглядеть одинаково у жюри |
| 20 | Цвета статусов из макета (#1F9D55, #B7791F, #D64545) используются для точек, полос и подчёркиваний; для текста бейджей взяты затемнённые оттенки (#136C3A, #8A5A12, #B42318) | Исходные цвета на светлых подложках дают контраст ниже WCAG AA (≈3,2–3,9:1); затемнённые — ≥ 4,5:1 |
| 21 | Шрифт: стек `Inter, Manrope, Segoe UI, Roboto…` без встраивания файлов | Отчёт остаётся одним офлайн-файлом без загрузки шрифтов из сети |
| 22 | Время шагов в таймлайне записывает пайплайн (`ctx.trace`); в HTML встроен и Markdown-отчёт — кнопка «Скачать отчёт» работает офлайн | Добавлены поля, существующие не менялись |
