# Демо ReqLens на защите — сценарий на 3 минуты

## Подготовка (до выхода на сцену)

1. Сделать **реальный прогон на Gemini** по документу организаторов — он станет записью для режима «Демо»:
   ```bash
   python review.py docs/requirements.md reports/report.md
   ```
2. (Для «До / После») прогнать исправленную версию, которую сделал агент:
   ```bash
   python review.py reports/report_requirements_fixed.md reports/v2/report.md
   ```
3. Запустить Studio **в режиме «Демо»** — сеть и квота модели на сцене не нужны:
   ```bash
   python -m req_review.web --demo reports/report.json --demo-after reports/v2/report.json
   ```
   Откроется `http://localhost:8000`. На стартовом экране — плашка «Режим «Демо» включён» и кнопка **«Демо»**.
   Загрузка своего файла по-прежнему запускает настоящую проверку (нужен ключ).

> Страховка: если в зале нет интернета или кончилась квота — режим «Демо» проигрывает сохранённый реальный прогон
> (шаги, пакеты, таблица, тайминги из трассировки) без обращения к модели. На экране это честно подписано.

## Сценарий

| Время | Что показываем | Что говорим |
|---|---|---|
| 0:00–0:20 | Стартовый экран Studio → кнопка **«Демо»** (или перетащить файл) | «Агент читает ТЗ банка и проверяет каждое требование по ISO/IEC/IEEE 29148.» |
| 0:20–0:50 | **Живой прогон**: таймлайн шагов, требования появляются в таблице пакетами | «Модель проверяет пакет, статус предварительный; итог — после проверки цитат кодом.» |
| 0:50–1:20 | Отчёт → **«Документ»**: подчёркивания по тяжести, `J` — следующий дефект, карточка | «Как проверка орфографии: критерий, объяснение и готовая правка прямо у фрагмента.» |
| 1:20–1:40 | В карточке — блок **«Основание»**: пункт стандарта / закон РК со ссылкой на adilet.zan.kz | «Замечание опирается на норму: фрагмент базы знаний с источником, не память модели.» |
| 1:40–2:00 | **«Граф»** (3D): красное ребро — противоречие; клик по узлу → цепочка конфликта | «500 000 ₸ в одном пункте и 300 000 ₸ в другом — агент видит набор целиком.» |
| 2:00–2:20 | **«Исправления»**: diff «было → стало», «по шаблону EARS», «Скачать исправленный документ» | «Не только находим, но и предлагаем формулировку по шаблону.» |
| 2:20–2:40 | **«До / После»**: проверить исправленную версию — балл и готовность растут | «После правок: балл N → M, критичных дефектов K → 0.» |
| 2:40–3:00 | **AI-ассистент**: «На какую норму опирается замечание к R-006?» → источники | «Любой вопрос по отчёту — ответ со ссылками на требования, строки и нормы.» |

## Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| Нет интернета / лимит API | Кнопка «Демо» — прогон проигрывается из записи |
| Не открывается 3D | Кнопка «2D» в разделе «Граф» (включается сама, если нет WebGL) |
| Вопрос не по шаблону | Ассистент отвечает по `report.json`; при лимите API — подсказкой, без зависания |
| Нужен отчёт на бумаге | `Ctrl+P` в HTML-отчёте — печатная версия A4 |
| Жюри говорит по-казахски | В отчёте пункт меню «Қазақша» — подписи интерфейса на казахском (содержание отчёта — на русском по ТЗ) |
