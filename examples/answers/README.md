# Пример: ответы аналитика → перепроверка

`organizers_answers.md` — 10 вымышленных ответов аналитика на вопросы отчёта ReqLens по документу организаторов
(`bench/real/notifications.md`): 6 конкретных, 2 уклончивых, 2 противоречивых. Ответы составлены командой своими
словами, чтобы показать, как агент учитывает каждый тип.

```bash
python review.py bench/real/notifications.md reports/answers/report.md --profile deep --answers examples/answers/organizers_answers.md
```

Ответы сопоставляются с вопросами нового прогона по служебной метке `<!-- reqlens: … -->`: для требования — ID и
критерий, для замечания к набору — критерий и затронутые требования (номера `S-xx` от прогона к прогону могут
меняться). Итог — раздел «Ответы аналитика» в «6. Итог», поле `answers` в `report.json`, исправленный документ с
формулировками из конкретных ответов.

## Тип ответа → ожидаемое → сделано верно

Колонка «Правила» — классификация правилами агента на вопросах отчёта v8.0.0 (без модели): совпала во всех 10 случаях.
Колонка «Прогон с моделью» заполняется по факту прогона командой выше (после сброса квоты, вместе с финальным отчётом).

| Вопрос | О чём | Ответ | Тип | Ожидаемое | Правила | Прогон с моделью |
|---|---|---|---|---|---|---|
| Q-01 | GET для сохранения (R-013, R-014) | PUT /alerts/limit, параметры в теле | конкретный | противоречие закрыто | ✅ | — |
| Q-02 | 200 с ERROR и 400 (R-039) | ошибка суммы — только 400 | конкретный | противоречие закрыто | ✅ | — |
| Q-06 | значение для Prod (R-017) | адрес Prod назван | конкретный | пропуск закрыт | ✅ | — |
| Q-21 | стык месяцев (R-011) | месяц — по дате совершения покупки | конкретный | противоречие закрыто | ✅ | — |
| Q-26 | 403 или 404 (R-043) | 403 — чужая карта, 404 — не найдена | конкретный | противоречие закрыто | ✅ | — |
| Q-35 | перцентиль срока push (R-006) | 60 с для 99 % событий | конкретный | замечание закрыто | ✅ | — |
| Q-04 | контракт события (R-006, R-008) | «согласуем позже» | уклончивый | остаётся открытым, с пометкой | ✅ | — |
| Q-30 | токен и сессия (R-015) | «пока не решено» | уклончивый | остаётся открытым, с пометкой | ✅ | — |
| Q-10 | пример приёмки 31 января (R-011) | счётчик растёт на 3 000 ₸ (в документе 4 000) | противоречивый | остаётся + замечание «ответ противоречив» | ✅ | — |
| Q-40 | Ф-2 и пример (R-003, R-011) | 5 000 ₸ к февралю (в документе 4 000) | противоречивый | остаётся + замечание «ответ противоречив» | ✅ | — |

Ничего не закрывается без дословной цитаты ответа: цитата хранится в `answers.items[].quote` и проверяется кодом как
подстрока ответа.
