# Слепая оценка ReqLens

Бенчмарк `bench/run.py` и разметка документа организаторов (`bench/real/`) составлены командой — это оценка «изнутри».
Слепая оценка проверяет агента на документах, которые команда **не писала и не видела** до прогона.

## Правила

1. **Документы пишет не команда.** Короткое финтех-ТЗ (1–3 страницы, MD / DOCX / PDF) с намеренно внесёнными дефектами
   готовит человек вне команды.
2. **Ключ хранится отдельно.** Автор документа присылает ключ дефектов отдельно от документа. До прогона ключ не кладётся
   в репозиторий и не открывается командой: папка `bench/blind/keys/` в `.gitignore`.
3. **Агент на них не настраивается.** После получения документов в правила, промпты и словари агента ничего не меняется
   до публикации результата. Прогон — один, профилем `deep`, с чистого коммита (паспорт отчёта это показывает).
4. **Результат публикуется как есть** — раздел «Слепые документы» в `bench/RESULTS.md`, вместе с моделью, версией агента
   и датой. Ключи после публикации можно добавить в репозиторий, чтобы результат можно было повторить.

## Формат

- Документ: `bench/blind/<имя>.md` (или `.docx`, `.pdf`).
- Ключ: `bench/blind/keys/<имя>.json` — тот же формат, что `bench/real/notifications.json`:

```json
{"document": "bench/blind/loans.md", "title": "…", "note": "кто составил ключ",
 "defects": [{"id": "B01", "severity": "critical", "title": "Порог не задан числом",
              "match": ["порог[^.]{0,120}(не задан|не указан)", "без числов\\w+ (порог|значени)"]}]}
```

`match` — регулярные выражения по тексту проблемы и рекомендации замечаний агента (не по цитате документа): «нашёл ли
агент эту проблему». Ключ составляет автор документа (или человек вне команды по его списку дефектов).

## Запуск

```bash
python bench/blind_eval.py
```

```bash
python bench/blind_eval.py --reports reports/blind --results
```

Первая команда прогоняет агента по всем документам, у которых есть ключ, и печатает таблицу. С `--results` раздел
«Слепые документы» записывается в `bench/RESULTS.md`; `--reports DIR` — оценить уже готовые отчёты `DIR/<имя>.json`
без нового прогона (квота не тратится); `--keys DIR` — ключи из другой папки.
