# Чистое ТЗ (вымышленное): Кэшбэк по выбранным категориям покупок

> Вымышленный документ с внесённым дефектом (генератор мутаций bench/mutate.py) — для замера ложных тревог агента. Не является документом организаторов.

## 1. Назначение и рамки

Функция начисляет держателю дебетовой карты кэшбэк за покупки в выбранных категориях.
Вне рамок: кэшбэк по кредитным картам, партнёрские акции, начисление бонусов в баллах.

## 2. Термины

- **Держатель** — клиент банка с дебетовой картой в тенге, вошедший в мобильное приложение.
- **Категория** — группа торговых точек по коду MCC из справочника «Категории кэшбэка».
- **Расчётный месяц** — календарный месяц по дате проведения покупки по времени Алматы (UTC+5).

## 3. Функциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CB-01 | Держатель выбирает до 3 категорий на следующий расчётный месяц до 23:59 последнего дня текущего месяца. | Высокий |
| CB-02 | Если держатель не выбрал категории, на следующий месяц сохраняются категории текущего месяца. | Средний |
| CB-03 | Кэшбэк — 5 % от суммы покупки в выбранных категориях и 0,5 % в остальных; сумма округляется вниз до 1 тенге. | Высокий |
| CB-04 | Кэшбэк за расчётный месяц не превышает 20 000 на одного держателя. | Высокий |
| CB-05 | Переводы, снятие наличных и пополнение электронных кошельков в кэшбэк не входят. | Высокий |
| CB-06 | Возврат покупки уменьшает кэшбэк того месяца, в котором была исходная покупка; частичный возврат уменьшает кэшбэк пропорционально сумме возврата; если кэшбэк этого месяца уже зачислен, сумма удерживается из следующего зачисления. | Средний |
| CB-07 | Кэшбэк за месяц зачисляется на карту до 10 числа следующего месяца; держатель получает push-уведомление с суммой. | Высокий |
| CB-08 | Экран «Кэшбэк» показывает сумму, ожидающую зачисления, с точностью до 1 тенге и историю начислений за 12 месяцев. | Низкий |

## 4. Нефункциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CBN-01 | Экран выбора категорий загружается не дольше 1,5 секунды для 95 % запросов при нагрузке до 200 запросов в секунду. | Средний |
| CBN-02 | Доступность сервиса кэшбэка — не менее 99,5 % в календарный месяц без учёта плановых работ, объявленных за 48 часов. | Средний |
| CBN-03 | Данные о начислениях передаются только по TLS версии 1.2 и выше. | Высокий |
| CBN-04 | Журнал аудита записывает каждое изменение категорий и каждое начисление: держатель, время, значение; журнал хранится 3 года. | Высокий |
| CBN-05 | Расчёт кэшбэка за месяц для 1 000 000 держателей завершается не более чем за 4 часа; при сбое расчёта мониторинг отправляет оповещение дежурной смене. | Средний |
| CBN-06 | Резервная копия данных начислений создаётся каждые 24 часа; RTO — 8 часов, RPO — 1 час. | Низкий |
| CBN-07 | Экраны кэшбэка доступны на казахском и русском языках и соответствуют WCAG 2.1 уровня AA. | Низкий |

## 5. Безопасность и соответствие

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CBS-01 | Экраны кэшбэка доступны только после входа в приложение по ПИН-коду или биометрии; сессия завершается после 10 минут бездействия. | Высокий |
| CBS-02 | Номер карты на экранах и в уведомлениях показывается маскированным: только последние 4 цифры. | Высокий |
| CBS-03 | Покупки с признаком мошенничества по данным антифрод-системы банка в кэшбэк не входят. | Средний |
| CBS-04 | Изменять справочник «Категории кэшбэка» может только сотрудник с ролью «Маркетинг». | Средний |

## 6. Ошибки

| Ситуация | Что видит держатель | Состояние |
| :--- | :--- | :--- |
| Выбрано больше 3 категорий | «Можно выбрать не более 3 категорий» | выбор не сохранён |
| Выбор после 23:59 последнего дня | «Выбор на следующий месяц закрыт» | действуют прежние категории |

## 7. Критерии приёмки

| Требование | Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| CB-01 | 31 января, 23:58 | Выбрать 3 категории | Выбор сохранён на февраль; четвёртая категория не выбирается |
| CB-02 | Категории января выбраны, на февраль — нет | Наступает 1 февраля | Действуют категории января |
| CB-03 | Покупка 1 999 ₸ в выбранной категории | Провести покупку | Начислено 99 ₸ |
| CB-04 | Кэшбэк за месяц 19 950 ₸ | Покупка с кэшбэком 100 ₸ | Итог за месяц 20 000 ₸ |
| CB-05 | Перевод 10 000 ₸ | Провести перевод | Кэшбэк не начислен |
| CB-06 | Покупка в январе с кэшбэком 50 ₸ | Возврат в феврале | Кэшбэк января уменьшен на 50 ₸ |
| CB-07 | Кэшбэк января 3 000 ₸ | Дождаться 10 февраля | 3 000 ₸ зачислено, push с суммой отправлен |
| CB-08 | Ожидает зачисления 1 234 ₸ | Открыть экран «Кэшбэк» | Показано 1 234 ₸ и история за 12 месяцев |
