# Чистое ТЗ (вымышленное): Онлайн-заявка на потребительский кредит

> Вымышленный документ с внесённым дефектом (генератор мутаций bench/mutate.py) — для замера ложных тревог агента. Не является документом организаторов.

## 1. Назначение и рамки

Функция позволяет клиенту банка подать заявку на потребительский кредит в мобильном приложении и получить деньги на карту.
Вне рамок: ипотека, автокредиты, кредиты юридическим лицам, досрочное погашение.

## 2. Термины

- **Заявитель** — клиент банка старше 21 года, вошедший в мобильное приложение.
- **Скоринг** — автоматическая оценка кредитоспособности заявителя действующей системой банка.
- **Одноразовый код** — шестизначный код из SMS, действующий 120 секунд с момента отправки.

## 3. Функциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CR-01 | Заявитель выбирает сумму кредита — целое число тенге от 50 000 до 5 000 000. | Высокий |
| CR-02 | Заявитель выбирает срок от 6 до 60 месяцев с шагом 6 месяцев. | Высокий |
| CR-03 | До отправки заявки система показывает ежемесячный платёж по аннуитетной схеме с точностью до 1 тенге. | Высокий |
| CR-04 | Заявитель указывает место работы и ежемесячный доход в тенге; доход — целое число от 1 до 100 000 000. | Высокий |
| CR-05 | Система отклоняет заявку, если ежемесячный платёж превышает 50 % указанного дохода, и показывает причину отказа. | Высокий |
| CR-06 | Решение по заявке возвращается не позднее 5 минут после отправки для 95 % заявок. | Высокий |
| CR-07 | При одобрении система показывает сумму, ставку, график платежей и текст договора. | Высокий |
| CR-08 | Договор подписывается одноразовым кодом из SMS; после 3 неверных вводов подписание блокируется на 30 минут. | Высокий |
| CR-09 | Кредит зачисляется на карту заявителя не позднее 15 минут после подписания договора. | Высокий |
| CR-10 | Заявитель может отменить заявку до подписания договора; отменённая заявка получает статус «Отменена». | Средний |
| CR-11 | От одного заявителя принимается не более 3 заявок за 30 календарных дней. | Средний |

## 4. Нефункциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CNF-01 | Расчёт ежемесячного платежа отвечает не дольше 1 секунды для 95 % запросов при нагрузке до 100 запросов в секунду. | Высокий |
| CNF-02 | Доступность сервиса заявок — не менее 99,5 % в календарный месяц без учёта плановых работ, объявленных за 48 часов. | Высокий |
| CNF-03 | Данные заявки передаются только по TLS версии 1.2 и выше и хранятся в зашифрованном виде алгоритмом AES-256. | Высокий |
| CNF-04 | Журнал аудита записывает каждое решение по заявке: заявитель, сумма, решение, время, правило скоринга; журнал хранится 5 лет. | Высокий |
| CNF-05 | Заявка и решение хранятся 5 лет с момента подачи, затем удаляются. | Средний |
| CNF-06 | При доле ошибок скоринга выше 2 % за 15 минут мониторинг отправляет оповещение дежурной смене. | Средний |
| CNF-07 | Резервная копия данных заявок создаётся каждые 24 часа; RTO — 4 часа, RPO — 15 минут. | Средний |
| CNF-08 | Экраны заявки доступны на казахском и русском языках и соответствуют WCAG 2.1 уровня AA. | Средний |

## 5. Безопасность и соответствие

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CS-01 | Заявка доступна только после входа в приложение по ПИН-коду или биометрии; сессия завершается после 10 минут бездействия. | Высокий |
| CS-02 | До запроса в кредитное бюро заявитель даёт согласие на обработку персональных данных отдельной отметкой; без согласия заявка не отправляется. | Высокий |
| CS-03 | Каждую заявку проверяет действующая антифрод-система банка; заявки с признаком мошенничества отклоняются. | Высокий |
| CS-04 | Кредитный аналитик видит заявку только с ролью «Кредитный аналитик». | Средний |
| CS-05 | Номер карты для зачисления показывается маскированным: только последние 4 цифры. | Средний |

## 6. Ошибки

| Ситуация | Что видит заявитель | Состояние |
| :--- | :--- | :--- |
| Сумма вне диапазона | «Сумма должна быть от 50 000 до 5 000 000 ₸» | заявка не создана |
| Платёж больше 50 % дохода | «Платёж превышает 50 % дохода» | заявка отклонена |
| Скоринг не ответил за 5 минут | «Заявка на рассмотрении, решение придёт push-уведомлением» | статус «На рассмотрении» |
| Три неверных кода | «Подписание заблокировано на 30 минут» | договор не подписан |

## 7. Критерии приёмки

| Требование | Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| CR-01 | Заявитель вошёл в приложение | Ввести 49 999 ₸, затем 5 000 001 ₸ | Обе суммы не принимаются; 50 000 ₸ и 5 000 000 ₸ принимаются |
| CR-02 | Открыт экран заявки | Выбрать срок | Доступны только 6, 12, …, 60 месяцев |
| CR-03 | Сумма 1 200 000 ₸, срок 24 месяца, ставка 20 % | Открыть расчёт | Платёж рассчитан по аннуитетной формуле с точностью до 1 ₸ |
| CR-04, CR-05 | Доход 200 000 ₸ | Запросить кредит с платежом 120 000 ₸ | Заявка отклонена с причиной «Платёж превышает 50 % дохода» |
| CR-06, CR-07 | Заявка соответствует условиям | Отправить заявку | Решение за 5 минут или раньше; показаны сумма, ставка, график и договор |
| CR-08 | Отправлен код | Ввести неверный код 3 раза | Подписание заблокировано на 30 минут |
| CR-09 | Договор подписан | Дождаться зачисления | Деньги на карте за 15 минут или раньше |
| CR-10 | Заявка одобрена, договор не подписан | Нажать «Отменить» | Статус «Отменена» |
| CR-11 | За 30 дней подано 3 заявки | Подать четвёртую | Сообщение «Не более 3 заявок за 30 дней» |
| CS-02 | Согласие не отмечено | Нажать «Отправить» | Заявка не отправлена, показано требование согласия |
