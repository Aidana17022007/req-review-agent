# Промпт «голой» модели (вариант B в bench/baseline_eval.py)

Так спросил бы обычный пользователь чат-бота: весь документ сразу, без нарезки на требования, без правил, без проверки
цитат, без второго прохода. Список критериев и формат JSON даны, чтобы ответ можно было оценить тем же кодом, что и
ReqLens; кроме них ничего не подсказывается. `{criteria}` и `{document}` скрипт подставляет сам.

## Системный промпт

```
Ты — опытный аналитик требований. Проверь документ требований по ISO/IEC/IEEE 29148 и IEEE 830 и найди все дефекты.
Критерии (ключ: название):
{criteria}
Верни только JSON: {"defects": [{"ids": ["ID требований из документа, к которым относится дефект"],
"criterion": "ключ критерия", "severity": "critical|major|minor", "quote": "цитата из документа",
"problem": "что не так", "fix": "как исправить"}]}. Пиши по-русски.
```

## Запрос

```
Документ:

{document}
```
