# Чистое ТЗ (вымышленное): Переводы по номеру телефона между клиентами банка

> Вымышленный документ без внесённых дефектов — для замера ложных тревог агента. Не является документом организаторов.

## 1. Назначение и рамки

Функция позволяет клиенту мобильного банка перевести деньги в тенге другому клиенту банка по номеру телефона.
Вне рамок: переводы в другие банки, переводы в валюте, переводы юридическим лицам.

## 2. Термины

- **Отправитель** — клиент банка, который выполняет перевод из мобильного приложения после входа в приложение.
- **Получатель** — клиент банка, к номеру телефона которого привязана активная карта в тенге.
- **Активная карта** — карта в статусе «Действует»: не заблокирована и срок действия не истёк.
- **Одноразовый код** — шестизначный код из SMS, действующий 120 секунд с момента отправки.

## 3. Функциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| TR-01 | Отправитель вводит номер телефона получателя в формате +7XXXXXXXXXX; поле принимает ровно 10 цифр после +7. | Высокий |
| TR-02 | После ввода номера система показывает имя получателя и первую букву фамилии не позднее 2 секунд для 95 % запросов. | Высокий |
| TR-03 | Если к номеру не привязана активная карта, система показывает сообщение «Получатель не найден» и не даёт продолжить. | Высокий |
| TR-04 | Сумма перевода — целое число тенге от 100 до 500 000 включительно. | Высокий |
| TR-05 | Сумма переводов одного отправителя за календарные сутки по времени Алматы не превышает 1 000 000 тенге. | Высокий |
| TR-06 | Перевод подтверждается одноразовым кодом из SMS; после 3 неверных вводов кода перевод отклоняется. | Высокий |
| TR-07 | Комиссия за перевод не взимается. | Средний |
| TR-08 | Деньги зачисляются на активную карту получателя не позднее 10 секунд после подтверждения для 99 % переводов. | Высокий |
| TR-09 | Повторный запрос с тем же идентификатором операции не создаёт второй перевод и возвращает статус первого. | Высокий |
| TR-10 | Отправитель и получатель получают push-уведомление с суммой и последними 4 цифрами номера карты не позднее 30 секунд после зачисления. | Средний |
| TR-11 | История переводов показывает дату, сумму, имя получателя и статус «Выполнен» или «Отклонён» за последние 12 месяцев. | Низкий |

## 4. Нефункциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| TNF-01 | Доступность сервиса переводов — не менее 99,9 % в календарный месяц без учёта плановых работ, объявленных за 48 часов. | Высокий |
| TNF-02 | Сервис выдерживает 300 переводов в секунду при времени ответа на подтверждение не более 1,5 секунды для 95 % запросов. | Высокий |
| TNF-03 | Данные передаются только по протоколу TLS версии 1.2 и выше; номера карт хранятся в зашифрованном виде алгоритмом AES-256. | Высокий |
| TNF-04 | Журнал аудита записывает каждый перевод: отправитель, получатель, сумма, время, результат; журнал хранится 5 лет. | Высокий |
| TNF-05 | Коды подтверждения, пароли и токены сессии в журналы не записываются. | Высокий |
| TNF-06 | При доле отклонённых переводов выше 5 % за 10 минут мониторинг отправляет оповещение дежурной смене. | Средний |
| TNF-07 | Резервная копия данных переводов создаётся каждые 24 часа; восстановление после сбоя — не более 4 часов (RTO), потеря данных — не более 15 минут (RPO). | Средний |
| TNF-08 | Экраны перевода доступны на казахском и русском языках и соответствуют WCAG 2.1 уровня AA. | Средний |

## 5. Безопасность и соответствие

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| TS-01 | Перевод доступен только после входа в приложение по ПИН-коду приложения или биометрии; сессия завершается после 10 минут бездействия. | Высокий |
| TS-02 | Каждый перевод проверяет действующая антифрод-система банка; переводы с признаком мошенничества отклоняются со статусом «Отклонён». | Высокий |
| TS-03 | Номер карты получателя на экранах и в уведомлениях показывается маскированным: только последние 4 цифры. | Высокий |
| TS-04 | Номер телефона получателя обрабатывается на основании согласия, данного клиентом при открытии счёта. | Средний |
| TS-05 | Сотрудник поддержки видит переводы клиента только с ролью «Поддержка» и только по обращению клиента. | Средний |

## 6. Ошибки

| Ситуация | Что видит отправитель | Состояние |
| :--- | :--- | :--- |
| Получатель не найден | «Получатель не найден» | перевод не создан |
| Недостаточно средств | «Недостаточно средств на карте» | перевод не создан |
| Превышен суточный лимит | «Превышен лимит переводов за сутки: 1 000 000 ₸» | перевод не создан |
| Три неверных кода | «Перевод отклонён: код введён неверно 3 раза» | перевод отклонён, деньги не списаны |
| Сервис зачисления недоступен более 10 секунд | «Перевод в обработке» | деньги зарезервированы; при отказе через 5 минут резерв снимается и перевод отклоняется |

## 7. Критерии приёмки

| Требование | Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| TR-01, TR-03 | Номер +77001234567 без активной карты | Ввести номер | Сообщение «Получатель не найден», кнопка «Продолжить» неактивна |
| TR-02 | Номер получателя с активной картой | Ввести номер | Имя и первая буква фамилии через 2 секунды или раньше |
| TR-04 | Баланс 600 000 ₸ | Ввести сумму 99 ₸, затем 500 001 ₸ | Обе суммы не принимаются; 100 ₸ и 500 000 ₸ принимаются |
| TR-05 | За сутки уже переведено 900 000 ₸ | Перевести 100 001 ₸ | «Превышен лимит переводов за сутки: 1 000 000 ₸» |
| TR-06 | Отправлен код | Ввести неверный код 3 раза | Перевод отклонён, деньги не списаны |
| TR-07, TR-08 | Баланс 10 000 ₸ | Перевести 5 000 ₸ и ввести верный код | Списано 5 000 ₸ без комиссии, получателю зачислено 5 000 ₸ за 10 секунд или раньше |
| TR-09 | Перевод с идентификатором A выполнен | Повторить запрос с идентификатором A | Второй перевод не создан, возвращён статус «Выполнен» |
| TR-10, TS-03 | Перевод выполнен | Дождаться уведомлений | Оба клиента получили push с суммой и последними 4 цифрами карты за 30 секунд или раньше |
| TR-11 | За 13 месяцев 5 переводов | Открыть историю | Показаны переводы только за последние 12 месяцев с датой, суммой, именем и статусом |
| TS-01 | Сессия без действий 10 минут | Открыть экран перевода | Требуется повторный вход |
