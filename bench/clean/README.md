# Чистые ТЗ — почему здесь нет дефектов

Восемь вымышленных, но полных документов требований, написанных командой ReqLens для замера ложных тревог агента
(`python bench/clean_eval.py`), и их перефразы (`python bench/clean/paraphrase.py` → `paraphrased/`). Это не копии
документа организаторов и не тексты других команд.

Каждый документ проверен по одному чек-листу (ISO/IEC/IEEE 29148, свойства отдельного требования и набора):

| Свойство | Как обеспечено во всех документах |
|---|---|
| Однозначность, проверяемость | у каждого правила — число, единица и граница («не позднее 10 секунд для 99 %», «от 100 до 500 000 включительно»); нет «быстро», «удобно», «и т. д.», «при необходимости» |
| Единичность | один пункт — одно правило; составные условия разнесены по ID |
| Полнота набора | термины определены в «Терминах»; ошибки — таблица «ситуация → сообщение → состояние»; рамки и «вне рамок» записаны явно |
| Непротиворечивость | одно значение каждого параметра в одном месте; примеры приёмки посчитаны по правилам документа |
| Трассируемость, ранжирование | уникальные ID, приоритет у каждого требования, строки приёмки ссылаются на ID правил |
| Проверяемость приёмкой | у каждого функционального правила — строка «исходные условия → действие → ожидаемый результат» |
| Безопасность и соответствие | вход и сессия, маскирование, журнал аудита без секретов, антифрод, согласие на обработку данных, роли |
| НФТ | доступность, производительность с перцентилем и нагрузкой, TLS и шифрование, мониторинг, RTO/RPO, языки KK/RU, WCAG |

| Документ | Тема | Особенность |
|---|---|---|
| transfers.md | переводы по номеру телефона | лимиты, идемпотентность, резерв при недоступности зачисления |
| credit.md | онлайн-кредит | согласие перед запросом в бюро, ограничение заявок |
| cards.md | перевыпуск карты | разные правила блокировки по причинам |
| cashback.md | кэшбэк по категориям | частичный возврат и возврат после зачисления |
| notifications.md | уведомление о пороге расходов (своя тема, не копия документа организаторов) | контракт события, методы чтения и записи, коды ошибок с машинным кодом |
| api_payments.md | API оплаты для партнёра | идемпотентность по ключу, 409 при конфликте, лимит запросов |
| onboarding.md | открытие счёта | биометрия, согласие, маскирование ИИН |
| deposit_kk.md | онлайн-депозит **на казахском** | ставки по сроку, ежемесячное начисление |

Чистоту второй раз проверяет человек 2 (или слепая модель): если находит настоящий дефект — документ исправляется,
а не агент. Перефразы меняют слова (показывает → отображает, не позднее → в пределах, …), но не термины, числа и ID.
