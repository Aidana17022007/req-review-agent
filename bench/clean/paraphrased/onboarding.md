# Чистое ТЗ (вымышленное): Открытие текущего счёта новым клиентом в мобильном приложении

> Перефраз чистого вымышленного документа: тот же смысл, другие формулировки; дефектов нет — для замера ложных тревог агента. Не является документом организаторов.

## 1. Назначение и рамки

Функция позволяет гражданину Казахстана старше 18 лет стать клиентом банка и открыть текущий счёт в тенге без визита в отделение.
Вне рамок: нерезиденты, счета в валюте, счета индивидуальных предпринимателей.

## 2. Термины

- **Заявитель** — гражданин Казахстана старше 18 лет с удостоверением личности.
- **Биометрическая проверка** — сравнение фото лица заявителя с фото из государственной базы с порогом сходства 0,85.
- **Одноразовый код** — шестизначный код из SMS, действующий 120 секунд с момента отправки.

## 3. Функциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| ON-01 | Заявитель вводит номер телефона и подтверждает его одноразовым кодом из SMS; после 3 неверных вводов новый код можно запросить через 5 минут. | Высокий |
| ON-02 | Заявитель вводит ИИН из 12 цифр; система проверяет контрольную цифру ИИН до запроса в государственную базу. | Высокий |
| ON-03 | Заявитель проходит биометрическую проверку; при сходстве ниже 0,85 даются ещё 2 попытки, после третьей неудачной заявка отклоняется. | Высокий |
| ON-04 | Система получает фамилию, имя, дату рождения и адрес регистрации из государственной базы и отображает их заявителю для подтверждения. | Высокий |
| ON-05 | Заявитель старше 18 лет по дате рождения из государственной базы; иначе заявка отклоняется с сообщением «Открытие счёта доступно с 18 лет». | Высокий |
| ON-06 | Заявитель подписывает договор банковского счёта одноразовым кодом из SMS. | Высокий |
| ON-07 | Счёт в тенге открывается в пределах 10 минут после подписания договора; заявитель получает push-уведомление с последними 4 цифрами номера счёта. | Высокий |
| ON-08 | Заявитель задаёт ПИН-код приложения из 4 цифр; ПИН-коды из одинаковых цифр (1111) и последовательностей (1234) не принимаются. | Средний |

## 4. Нефункциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| ONF-01 | Биометрическая проверка отвечает не более 5 секунд для 95 % запросов при нагрузке до 50 запросов в секунду. | Высокий |
| ONF-02 | Доступность сервиса открытия счёта — не менее 99,5 % в календарный месяц без учёта плановых работ, объявленных за 48 часов. | Высокий |
| ONF-03 | Фото лица и данные удостоверения передаются исключительно по TLS версии 1.2 и выше и хранятся в зашифрованном виде алгоритмом AES-256; фото удаляется через 30 дней после решения. | Высокий |
| ONF-04 | В журнал аудита записывается каждый шаг заявки: заявитель (ИИН маскирован: первые 6 цифр), шаг, результат, время; журнал хранится 5 лет. | Высокий |
| ONF-05 | При доле отказов биометрии выше 20 % за 30 минут дежурная смена получает оповещение от мониторинга. | Средний |
| ONF-06 | Резервное копирование заявок выполняется каждые 24 часа; RTO — 4 часа, RPO — 15 минут. | Низкий |
| ONF-07 | Экраны открытия счёта доступны на казахском и русском языках и соответствуют WCAG 2.1 уровня AA. | Средний |

## 5. Безопасность и соответствие

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| ONS-01 | До запроса в государственную базу заявитель даёт согласие на обработку персональных данных отдельной отметкой; без согласия шаг недоступен. | Высокий |
| ONS-02 | ИИН на экранах отображается маскированным: первые 6 цифр, остальные — звёздочки. | Высокий |
| ONS-03 | Каждую заявку проверяет антифрод- и AML-система банка; заявки с признаком риска передаются сотруднику с ролью «Комплаенс». | Высокий |
| ONS-04 | Сессия заявки завершается после 15 минут бездействия; продолжить можно с последнего пройденного шага в течение 24 часов. | Средний |

## 6. Ошибки

| Ситуация | Что видит заявитель | Состояние |
| :--- | :--- | :--- |
| Неверная контрольная цифра ИИН | «Проверьте ИИН» | заявка не создана |
| Государственная база недоступна | «Сервис временно недоступен, попробуйте через 10 минут» | заявка сохранена на текущем шаге |
| Три неудачные биометрические проверки | «Не удалось подтвердить личность. Обратитесь в отделение» | заявка отклонена |

## 7. Критерии приёмки

| Требование | Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| ON-01 | Код отправлен | Ввести неверный код 3 раза | Новый код доступен через 5 минут |
| ON-02 | — | Ввести ИИН с неверной контрольной цифрой | «Проверьте ИИН», запрос в базу не отправлен |
| ON-03 | Сходство 0,80 | Пройти проверку 3 раза | Заявка отклонена |
| ON-04 | ИИН верный | Продолжить | Показаны ФИО, дата рождения и адрес из базы |
| ON-05 | Дата рождения — 17 лет назад | Продолжить | «Открытие счёта доступно с 18 лет» |
| ON-06, ON-07 | Данные подтверждены | Подписать договор кодом | Счёт открыт за 10 минут или раньше, push с последними 4 цифрами |
| ON-08 | — | Задать ПИН 1111, затем 1234 | Оба не приняты |
| ONS-01 | Согласие не отмечено | Нажать «Далее» | Шаг недоступен |
