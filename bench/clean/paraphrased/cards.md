# Чистое ТЗ (вымышленное): Перевыпуск банковской карты в мобильном приложении

> Перефраз чистого вымышленного документа: тот же смысл, другие формулировки; дефектов нет — для замера ложных тревог агента. Не является документом организаторов.

## 1. Назначение и рамки

Функция позволяет держателю заказать перевыпуск своей дебетовой карты в тенге и получить её в отделении банка.
Вне рамок: доставка курьером, перевыпуск кредитных карт, выпуск дополнительных карт.

## 2. Термины

- **Держатель** — клиент банка, на имя которого выпущена дебетовая карта в тенге.
- **Перевыпуск** — выпуск новой карты к тому же счёту взамен действующей.
- **Одноразовый код** — шестизначный код из SMS, действующий 120 секунд с момента отправки.

## 3. Функциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| CRD-01 | Держатель заказывает перевыпуск по одной из причин: истекает срок действия, карта повреждена, карта утеряна. | Высокий |
| CRD-02 | Перевыпуск по сроку действия доступен не ранее чем за 60 дней до окончания срока карты. | Высокий |
| CRD-03 | При причине «карта утеряна» старая карта блокируется сразу с момента подтверждения заказа. | Высокий |
| CRD-04 | При остальных причинах старая карта работает до активации новой, но не дольше окончания её срока действия. | Высокий |
| CRD-05 | Держатель выбирает отделение для получения из списка отделений своего города. | Средний |
| CRD-06 | Заказ подтверждается одноразовым кодом из SMS; после 3 неверных вводов заказ отменяется. | Высокий |
| CRD-07 | Комиссия за перевыпуск по сроку действия — 0 тенге, по остальным причинам — 1 000 тенге, списывается при подтверждении заказа. | Высокий |
| CRD-08 | Карта готова к выдаче в пределах 5 рабочих дней после заказа; держатель получает push-уведомление о готовности. | Средний |
| CRD-09 | Новая карта активируется в приложении вводом последних 4 цифр её номера. | Высокий |
| CRD-10 | Невыданная карта хранится в отделении 60 дней, затем уничтожается; держатель получает push-уведомление за 7 дней до уничтожения. | Низкий |

## 4. Нефункциональные требования

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| KNF-01 | Оформление заказа отвечает не более 2 секунд для 95 % запросов при нагрузке до 50 запросов в секунду. | Средний |
| KNF-02 | Доступность сервиса заказа — не менее 99,5 % в календарный месяц без учёта плановых работ, объявленных за 48 часов. | Высокий |
| KNF-03 | Данные передаются исключительно по TLS версии 1.2 и выше. | Высокий |
| KNF-04 | В журнал аудита записывается каждый заказ и блокировку карты: держатель, причина, время, сотрудник выдачи; журнал хранится 5 лет. | Высокий |
| KNF-05 | Мониторинг отправляет оповещение дежурной смене, если заказы не передаются в процессинг дольше 30 минут. | Средний |
| KNF-06 | Резервное копирование данных заказов выполняется каждые 24 часа; RTO — 8 часов, RPO — 1 час. | Низкий |
| KNF-07 | Экраны заказа доступны на казахском и русском языках и соответствуют WCAG 2.1 уровня AA. | Средний |

## 5. Безопасность и соответствие

| ID | Требование | Приоритет |
| :--- | :--- | :--- |
| KS-01 | Заказ открывается только после входа в приложение по ПИН-коду или биометрии; сессия завершается после 10 минут бездействия. | Высокий |
| KS-02 | Номер карты на экранах и в уведомлениях отображается маскированным: только последние 4 цифры; CVV и ПИН-код карты не хранятся. | Высокий |
| KS-03 | Сотрудник отделения выдаёт карту только по удостоверению личности держателя и видит заказ только с ролью «Выдача карт». | Высокий |
| KS-04 | Заказы с признаком мошенничества по данным антифрод-системы банка отклоняются. | Средний |

## 6. Ошибки

| Ситуация | Что видит держатель | Состояние |
| :--- | :--- | :--- |
| Срок карты истекает позже чем через 60 дней | «Перевыпуск по сроку доступен за 60 дней до окончания» | заказ не создан |
| Недостаточно средств для комиссии | «Недостаточно средств для оплаты комиссии 1 000 ₸» | заказ не создан |
| Три неверных кода | «Заказ отменён: код введён неверно 3 раза» | заказ отменён |

## 7. Критерии приёмки

| Требование | Исходные условия | Действие | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| CRD-01, CRD-02 | Срок карты истекает через 61 день | Выбрать причину «истекает срок» | Сообщение о доступности за 60 дней, заказ не создан |
| CRD-03 | Карта активна | Заказать перевыпуск с причиной «карта утеряна» | Старая карта заблокирована сразу с момента подтверждения |
| CRD-04 | Карта повреждена | Заказать перевыпуск | Старая карта работает до активации новой |
| CRD-05 | Держатель из Алматы | Открыть выбор отделения | Показаны только отделения Алматы |
| CRD-06 | Отправлен код | Ввести неверный код 3 раза | Заказ отменён |
| CRD-07 | Баланс 5 000 ₸ | Заказать перевыпуск по причине «повреждена» | Списано 1 000 ₸ |
| CRD-08 | Заказ создан | Дождаться готовности | Push о готовности в пределах 5 рабочих дней |
| CRD-09 | Новая карта выдана | Ввести последние 4 цифры | Карта активирована |
| CRD-10 | Карта не выдана 53 дня | Дождаться | Push о предстоящем уничтожении за 7 дней |
