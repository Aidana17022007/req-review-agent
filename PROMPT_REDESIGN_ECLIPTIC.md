## Роль и цель

Ты — senior продуктовый дизайнер и фронтенд-разработчик. Проект — **ReqLens**, ИИ-агент статической проверки требований
по ISO/IEC/IEEE 29148 и IEEE 830 (Python, Jinja2-шаблоны в `req_review/ui/templates/`, один CSS
`req_review/ui/assets/base.css`, токены в `design/tokens.json` → `req_review/ui/tokens.css`).

Задача: перевести **весь продукт** — лендинг, веб-студию (Studio), HTML-отчёт, витрину стилей, слайды, логотип/иконки/PWA,
баннер и скриншоты README — на визуальный язык шаблона Oversight **«Ecliptic»**
(https://supply.madebyoversight.com/templates/ecliptic) так, чтобы всё выглядело **одним продуктом** с «вау»-эффектом
с первого экрана.

Нынешний дизайн (тёмно-зелёный, плотный, мелкий) **полностью заменяется**. Зелёный бренд больше не обязателен.

**Если есть исходники** в `design/reference/ecliptic/` — сначала изучи их: шрифты, размеры, радиусы, градиенты,
отступы, анимации — и используй точные значения вместо приблизительных ниже. Если исходников нет — **не копируй**
код, тексты и картинки шаблона (он платный), воспроизводи только визуальное направление, описанное здесь, на своём контенте.

## Визуальный язык Ecliptic

**Идея:** глубокий космос → рассвет. Почти чёрная ночь, из которой снизу поднимается кобальтово-синий свет, переходящий в
лавандово-розовую зарю. Над светом в перспективе парят наклонённые тёмные экраны продукта. Огромная, плотная, спокойная
типографика. Мало элементов — много света и воздуха.

**Палитра (снята с превью, тёмная тема — основная):**

| Роль | Цвет |
|---|---|
| Ночь (фон панелей) | `#02030C` |
| Глубокий синий | `#080F36` |
| Поверхность / карточка | `#0B0E24`, приподнятая `#12163A` |
| Кобальт (основной бренд) | `#3B4CB6`, ярче `#4459C8` |
| Перивинкл (акцент, ссылки, фокус) | `#8E9BFF` / `#9191D3` |
| Заря (низ градиента) | `#D9C6DA`, `#E3CDDB` |
| Внешний фон страницы | вертикальный градиент `#333E9F → #3B4CB6 → #7E82CE → #E3CDDB` |
| Текст | `#F4F5FF`, вторичный `#A3A8C9`, третичный `#6E7397` |
| Рамки | `rgba(140,155,255,.14)`, на стекле `rgba(255,255,255,.08)` |

**Главный градиент «рассвет» (hero):**
`linear-gradient(180deg, #02020E 0%, #02020E 30%, #080F36 42%, #192B84 52%, #4459C8 62%, #9191D3 74%, #D9C6DA 88%, #E3CDDB 100%)`
плюс мягкий radial-свет `radial-gradient(60% 40% at 50% 60%, rgba(68,89,200,.55), transparent)`.

**Композиция «панели на градиенте»:** вся страница — это фон-градиент (индиго → розовый), на котором лежат **огромные
скруглённые панели** (`border-radius: 32–40px`, отступ от краёв экрана 16–24px, между панелями 16px) с ночным фоном
`#02030C`. Каждая секция сайта — отдельная такая панель. Это главный приём шаблона.

**Парящие экраны:** 3 скриншота продукта в тёмной рамке, повёрнутые в перспективе:
`transform: perspective(1600px) rotateX(18deg) rotateY(var(--ry)) translateZ(var(--z))` с `--ry` −14° / 0° / 14°,
верхние края уходят в темноту (`mask-image: linear-gradient(to bottom, #000 40%, transparent)`), под ними — синее свечение.
Во второй секции — плитки KPI, лежащие «на полу» в перспективе с размытием по краям (depth-of-field: `filter: blur()` у дальних).

**Типографика:** гротеск с плотным кернингом — `Inter Display` / `Geist` / `Manrope` (подключить локально, с fallback на
системный). Заголовки: вес 500, `letter-spacing: -0.04em`, `line-height: 1.02`.
display 72–88px (мобильный 40–44px), h1 56px, h2 40px, h3 20px, body 16px/1.6, small 14px, caption 12px.
Цифры (баллы, KPI) — `font-variant-numeric: tabular-nums`.

**Компоненты:**
- кнопка primary — белая таблетка `#FFFFFF`, текст `#02030C`, высота 40px, радиус 999px, иконка-шеврон справа;
- кнопка secondary — тёмно-синяя таблетка `#0B0E24` с рамкой `rgba(140,155,255,.22)` и шевроном;
- навигация — капсула по центру с тонкой рамкой и стеклом (`backdrop-filter: blur(14px)`), логотип слева, «Войти» + белая кнопка справа;
- карточки — `#0B0E24`, рамка `rgba(140,155,255,.12)`, радиус 20px, при hover — подсветка рамки перивинклом и подъём на 2px;
- чипы — маленькие таблетки 12px, полупрозрачный фон.

**Цвета серьёзности на ночном фоне (обязательно контраст ≥ 4.5 — WCAG AA):**
критичное `#FF7B8A` (soft `rgba(255,123,138,.14)`), существенное `#FFB86B`, незначительное `#F3DE8A`,
ок `#5EE6B0`, инфо `#8E9BFF`. В светлой теме — более тёмные варианты (`#C0263A`, `#9A5A00`, `#7A6A00`, `#0E7A52`, `#3B4CB6`).

**Движение:** экраны в hero при загрузке «вплывают» снизу (translateY 40px → 0, rotateX 30° → 18°, 900ms
`cubic-bezier(.2,.8,.2,1)`), лёгкий параллакс при скролле; свет рассвета медленно «дышит» (10–12 с).
Всё выключается при `prefers-reduced-motion`.

**Светлая тема (вторичная, обязательная):** фон `#F5F6FC`, поверхности `#FFFFFF`, текст `#0A0D2A`, бренд `#3B4CB6`,
рамки `rgba(10,13,42,.08)`, градиент рассвета остаётся в hero, но панели белые. **По умолчанию — тёмная тема.**

## ЭТАП 1 — сайт (лендинг)

Одностраничный адаптивный сайт в `site/`: чистый HTML + CSS + немного JS, без фреймворков и трекеров. Стили —
`req_review/ui/tokens.css` (общие токены с приложением) + `site/site.css`. Тексты свои, на русском, переключатель RU / KK.

Панели (каждая — скруглённая ночная панель на градиентном фоне):
1. **Hero** — навигация-капсула; три парящих экрана ReqLens (тёмные скриншоты: `screenshot-doc-dark.png`,
   `screenshot-graph-dark.png`, `screenshot-overview-dark.png`); под ними на рассвете — огромный заголовок
   «Требования без дефектов — / до первой строки кода.», подзаголовок про ISO 29148 / IEEE 830 и отчёт на русском,
   белая кнопка «Проверить документ ›» и тёмная «Смотреть демо ›».
2. **Логотипы стандартов и моделей** — ISO/IEC/IEEE 29148, IEEE 830, Gemini, OpenAI-compatible, Ollama — монохромной строкой.
3. **«Создано вокруг вашего процесса»** — заголовок слева, под ним плитки KPI в перспективе: 26 из 26 дефектов,
   recall 100 %, precision 98 %, 43 требования / 75 замечаний (данные из `README.md` и `bench/RESULTS.md`).
4. **Возможности** — сетка 10 карточек (тест-проба Given/When/Then, интерактивный отчёт, автоисправление, защита от
   галлюцинаций, финтех-чек-лист, метрики, офлайн, для команды, 3D-граф, Studio + ассистент). В каждой — кроп реального UI.
5. **Как это работает** — 4 шага по горизонтали с линией-градиентом кобальт → перивинкл; справа `docs/assets/live-run.gif` в рамке.
6. **Скриншоты** — табы-таблетки: Документ / 3D-граф / Тесты / Исправления / Studio; экран в перспективе меняется с анимацией.
7. **Бенчмарк** — таблица 5 документов / 67 дефектов.
8. **Быстрый старт** — блок кода с кнопкой «Скопировать»: `python review.py bench/real/notifications.md reports/report.md --profile deep`.
9. **Финальный CTA** — снова свет рассвета снизу и белая кнопка; **футер** — команда из `docs/team.yaml`, GitHub, лицензия.

Требования: 360 / 768 / 1280 / 1440px без горизонтального скролла; Lighthouse ≥ 90 (Performance, Accessibility);
картинки WebP с `width/height` и `loading="lazy"`; семантичная вёрстка, alt-тексты, видимый фокус; страница читается без JS.

## ЭТАП 2 — весь проект под дизайн сайта

Единственный источник правды — `design/tokens.json`. Работай по шагам и коммить после каждого:

1. **Токены** → `design/tokens.json` версии `4.0.0`, `"system": "Дизайн-система v3 — Ecliptic Dawn"`:
   новая палитра `indigo` 50–950 (вместо `green`) и `night` (вместо `gray`), семантика `color.dark` / `color.light` из таблицы выше,
   новые группы `gradient` (`dawn`, `page`, `glow`), `glass` (bg, border, blur), `perspective` (угол, глубина),
   радиусы `panel: 36px`, `card: 20px`, `control: 999px`, тень `xl: 0 40px 120px rgba(2,3,12,.6)`,
   шрифт `display` и роль `--t-display` 72px. Затем `python -m req_review.ui.styleguide`. `tokens.css` руками не правь.
   Проверь `req_review/ui/a11y.py` — таблица контраста должна пройти для новых пар.
2. **`base.css`** — перерисуй все компоненты из `docs/DESIGN_SYSTEM.md` (кнопки, поля, dropzone, чипы, карточки, KPI,
   таблицы, табы, seg, drawer, modal, toast, tooltip, stages/stepper, empty, skeleton) только через семантические токены.
   **Имена классов и разметку не меняй** — шаблоны и JS должны работать без правок логики.
3. **Studio** (`studio.html.j2`) — фон-градиент страницы + основная ночная панель с радиусом `panel`; сайдбар — стеклянная
   колонка; dropzone — большая область со светом рассвета снизу, при `.is-over` свет усиливается; живой прогон, ассистент
   и «До / После» — в карточках нового стиля.
4. **HTML-отчёт** (`report.html.j2`, `report.js`, `report-graph.js`) — тот же язык: шапка-капсула, KPI с крупными цифрами,
   карточки замечаний, подчёркивания дефектов цветами серьёзности, миникарта, радар (линии перивинкл), 3D-граф на ночном фоне
   с синим туманом (узлы — цвета серьёзности, рёбра противоречий — `#FF7B8A` со свечением).
   **Отчёт обязан остаться одним офлайн-файлом**: никаких CDN и внешних шрифтов (шрифт — встроенный subset или системный).
   Печать в PDF — светлая тема без градиентов, blur и анимаций.
5. **Витрина и слайды** (`styleguide.html.j2`, `slides.html.j2` → `design/styleguide.html`, `docs/slides.html`) — в том же стиле:
   каждый слайд — ночная панель на градиенте рассвета.
6. **Бренд** (`req_review/ui/brand.py` → `design/brand/`): новый знак ReqLens — линза/кольцо с градиентом кобальт → лаванда на
   ночной плитке; `favicon.svg`, PNG-иконки, `maskable` (глиф в безопасной зоне 80 %), `apple-touch-icon`,
   `reqlens-logo-light/dark.svg`, `brand.json` (`theme_color #02030C`, `background_color #F5F6FC`, `background_color_dark #02030C`),
   `req_review/web/static/` (иконки, `manifest.webmanifest`, `offline.html`), `docs/assets/banner.svg` (градиент рассвета + название).
7. **Скриншоты и GIF** — `python scripts/screenshots.py`; в README сначала тёмные версии, бейджи shields — в цветах палитры.
8. **Документация** — перепиши `docs/DESIGN_SYSTEM.md` под v3: палитра, градиенты, панели, перспектива, правила
   («один источник света на экран», «не больше трёх парящих экранов», «белая кнопка — одна главная на экран»).

## Проверка (обязательно)

- `pytest` — все тесты зелёные, включая `tests/test_design.py` (tokens.css ↔ tokens.json, z-index ≤ 9, контраст AA в обеих темах).
  Если тест проверяет старые значения (например, зелёный `theme_color`) — обнови тест вместе с токенами, не отключай его.
- Сними сайт, Studio и отчёт в тёмной и светлой теме на 390 и 1440px и сравни рядом: одинаковые фон, панели, кнопки, чипы,
  шрифты, радиусы, свет. Всё, что выбивается, — исправь.
- Нет ошибок в консоли; `prefers-reduced-motion` выключает анимации; отчёт открывается офлайн одним файлом.
- В конце — список изменённых файлов и скриншоты «до / после».

Работай в ветке `design-v3-ecliptic`, коммить по шагам: токены → компоненты → studio → отчёт → витрина/слайды → бренд → скриншоты → документация.
