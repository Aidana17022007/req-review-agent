# База знаний ReqLens (RAG)

| Папка | Что внутри | Лицензия |
|---|---|---|
| `standards/` | краткие пересказы критериев ISO/IEC/IEEE 29148 §5.2.5/5.2.6 и IEEE 830 §4.3 — по одному разделу на критерий | собственный пересказ (стандарты платные — их текст сюда не кладём) |
| `law_kz/` | пересказ норм РК, важных для финтех-требований: персональные данные, банковская тайна, платежи, ИБ | собственный пересказ; перед ссылкой на норму сверить актуальную редакцию на adilet.zan.kz |
| `patterns/` | шаблоны хороших требований (EARS) «плохо → хорошо» | собственные шаблоны |

Формат файла: метаданные между `---` (title, license, url) и разделы `## <ключ> · <пункт> <название>`.
Ключ раздела в `standards/` совпадает с ключом критерия (`verifiable`, `set_consistent`…) — по нему замечание
получает поле `basis`. Цитата в `basis` — всегда дословный фрагмент файла базы знаний.

Собрать индекс: `python -m req_review.rag build`; поиск: `python -m req_review.rag search "порог уведомления"`.
